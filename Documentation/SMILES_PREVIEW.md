# Unfinished SMILES preview

`CDKSmilesPreview.evaluate(_:)` is a separate, bounded display API. Ordinary
`CDKSmilesParser` entry points remain strict by default. Applications must parse
the original source again before saving, searching, calculating properties or
exporting; a preview graph is never a validated molecule contract.

The result distinguishes empty, complete, incomplete, invalid, unsupported and
resource-limited input. It accepts one ordinary SMILES record, optionally followed
by a title. Reactions, CXSMILES, multiline records and other document formats are
outside this preview API. Limits are 1,024 UTF-8 bytes and 96 atoms; cancellation
is propagated rather than reported as invalid chemistry.

Only an unfinished end of input is recoverable: bracket atoms, percent ring
numbers, missing ring closures, open branches, trailing bonds and trailing dots.
Atoms read before an unfinished token can be depicted. No atom, missing endpoint
or ring closure is supplied automatically. Incomplete graphs omit stereochemistry;
completing the input reparses the original source and restores its explicit stereo.
Coordinates are not generated by the API. Malformed interior syntax produces an
invalid result with no graph. A complete result means a completed parse, not proof
of physical feasibility or an independent validation of valence.

The API is inspired by the reader-mode changes in CDK 2.14, but is deliberately
separate from the strict parser contract. It is not a claim of full Java CDK
relaxed-reader parity. The package contains no Java implementation or runtime.
Upstream reference: https://github.com/cdk/cdk/releases/tag/cdk-2.14

Tests cover incomplete prefixes, malformed syntax, graph/stereo equivalence after
completion, unsupported formats, cancellation and both resource bounds. Strict
parsing also rejects empty branches, repeated bond tokens, dangling fragment
separators and self/duplicate ring bonds. A historical depiction fixture placed a
bond token before an opening branch; it now places that bond inside the branch,
retaining the intended two-hydrogen alkene depiction.
